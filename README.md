# Responsive Scaffold - HW #2

The MMED-1056 HW#2 is a one-page responsive scaffold for the wireframe provided. The page focuses on using a grid utility system and media queries to help create responsiveness.

## 💾 Installation
No installation required. Download the zip file and extract it.

## 🌐 Usage
Open the `index.html` file in the browser of your choice.
